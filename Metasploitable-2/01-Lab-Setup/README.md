# Setup of Metasploitable2 and Kali Linux in VirtualBox 
## Metasploitable 
### What is Metaploitable2
*Metasploitable* is an intentionally vulneable virtual machine (VM) created by Rapid7 for learning and practicing *Cybersecurity*,*Penetration testing*, and *Vulnerability assessment (VAPT)*.

Think of it as a deliberately vulnerable computer that you can legally attack in your own lab to learn how real-world vulnerabilities work.
